•Objective: Utilize pipelines to process and output large-scale biological data, along with providing
accessible tools for its interpretation. <br/>
• Standardization: Uniformly process data so results are comparable across datasets and tissue types.<br/>
• Tools: Use Python (Jupyter Notebook), along with open-source tools such as Scanpy (Python
toolkit), and AnnData (Python data structure).<br/>
• Environment: All computation is run in high-performance UNIX environments.<br/>
• Products: Strive for outputs that are clean, structured datasets ready to be explored, visualized, or
annotated.
